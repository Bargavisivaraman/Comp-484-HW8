# COMP 484 - HW8 Resume Site

## Live Site
https://bargavisivaraman.github.io/Comp-484-HW8/

## Description
This is my personal resume website built for COMP 484 Web Development.
It is a continuation of HW6 and HW7 with the following new features added in HW8.

## HW8 Features Added

### 1. Navigation Menu (no list)
- Sticky nav bar that stays at the top when scrolling
- Built using plain `<a>` tags inside a `<div>` — no `<ul>` or `<li>` used
- Links to every section: About, Skills, Experience, Education, Projects, Contact
- Includes a PDF download link for the resume

### 2. FontAwesome Icons in Footer
- Added FontAwesome CDN to the project
- Icons added to every contact item in the footer (email, LinkedIn, GitHub, location, PDF)
- Circular social icon buttons with brand icons

### 3. Background Image with RGBA Gradient
- Work Experience section has a background photo
- CSS linear-gradient using rgba() alpha transparency layered over the image
- Makes text readable while showing the background image

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Merriweather, Open Sans)
- FontAwesome 6
- GitHub Pages
